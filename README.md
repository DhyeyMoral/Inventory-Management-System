# Inventory Management System

A simple web-based Inventory Management System built with HTML, CSS, and JavaScript. The project provides separate interfaces for administrators and staff to manage, search, view, and monitor product information.

## Features

### Admin Portal
- Admin login and account creation
- Admin dashboard
- Add product
- Edit product
- View product details

### Staff Portal
- Staff login and account creation
- Staff dashboard
- Search products
- View product details
- Check stock status

### Validation
- JavaScript-based form validation is included for project forms.

## Technologies Used

- HTML5
- CSS3
- JavaScript

No package manager, framework, or build system is required for the current project.

## Getting Started

### Prerequisites

A modern web browser such as Google Chrome, Microsoft Edge, or Mozilla Firefox is sufficient to run the current project.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/DhyeyMoral/Inventory-Management-System.git
   ```
2. Open the project directory:
   ```bash
   cd Inventory-Management-System
   ```
3. Open `index.html` in a web browser.

For a local development server, the project can also be opened through any simple static-file server.

## Usage

1. Open `index.html`.
2. Select the Admin or Staff login option.
3. Navigate through the available dashboard and product-management pages.
4. Use the forms and search/stock-status pages provided by the project.
